# Simulation Results

This folder documents the preliminary simulation comparing checkpoint policies for chained tool-calling workflows.

## Files

- `checkpoint_comparison_v2.csv` — comparison of success rate, average checks, propagated steps, and recoveries.
- `checkpoint_success_rate.png` — graph comparing the simulated success rates.

## Limitation

These results are generated by a simplified simulation and depend on the assumptions in the Python code. They do not establish real-world agent performance.
